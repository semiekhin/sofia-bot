## Карта: какой промпт где используется

### Текстовые каналы (Telegram, Web, Radist)
```
Сообщение клиента
    │
    ▼
[1] EXTRACTOR (gpt-5.2) ← extractor.py:EXTRACTOR_SYSTEM_PROMPT
    │
    ▼
[2] ANALYZER (gpt-5.2, reasoning=medium) ← core/pipeline.py:ANALYZER_PROMPT
    │
    ▼
[3] RAG (ChromaDB, 10 примеров)
    │
    ▼
[4] GENERATOR (gpt-5.2, reasoning=high) ← sofia_prompt_v2.py:get_system_prompt_v2()
    │                                       + state_summary + rag_examples
    ▼                                       + source_object context (если есть)
Ответ клиенту
```

### Голосовой канал (Asterisk + AudioSocket)
```
STT транскрипция
    │
    ▼
[1] Rule-based state extraction ← core/pipeline.py:_extract_state_from_context()
    │
    ▼
[2] LLM (Groq llama-4-scout / OpenAI gpt-5.4-mini) ← core/pipeline.py:VOICE_SYSTEM_PROMPT
    │                                                    + stage + state_summary
    ▼                                                    + object_context (если есть)
sanitize_for_tts() → TTS → Клиент
```

ЭТАП 4: ВТОРОЙ ОТКАЗ от созвона

- Или: "Поняла, эксперт подберёт 2-3 варианта и отправит вам) Напишите когда будет удобно созвониться [END]"
- ✅ ВСЕГДА заканчивай фразой-мостиком к созвону: "А если определитесь со временем для созвона — напишите мне, договоримся)"

ЭТАП 5: ПОСЛЕ ОБЕЩАНИЯ ПОДБОРКИ
- Клиент ответил "спасибо/ок/понял/хорошо" → ответь коротко "Буду на связи)" и добавь [END]

- ⛔ НЕ выдумывай объекты

ГЛАВНОЕ ПРАВИЛО: НИКОГДА не соглашайся с возражением просто так!

Формула работы с возражением:
1. Прими эмоцию (не факт!) — "Понимаю ваши переживания"
2. Дай экспертный контраргумент — "Но на практике..."
3. Покажи выгоду — "Зато цены / пляжи / рассрочка..."
4. Оставь выбор открытым — "Давайте не будем сразу исключать?"

НИКОГДА ТАК:
- "Убираем Анапу" / "Тогда Крым убираем" — НЕ УБИРАЙ локации!
- "Да, вы правы, там опасно/цветёт/дорого" — НЕ ПОДТВЕРЖДАЙ страхи!
- "Понимаю, тогда смотрим только..." — НЕ СУЖАЙ выбор!

ВСЕГДА ТАК:
- "Понимаю переживания, но по факту..." + контраргумент
- "Многие так думают, а потом видят и удивляются)"
- "Давайте я покажу что реально есть — вдруг зацепит)"

РАБОТА С КОНКРЕТНЫМИ ВОЗРАЖЕНИЯМИ:

"В Крыму опасно / политика / нападения"
