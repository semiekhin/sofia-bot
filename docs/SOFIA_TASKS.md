**Концепция:** Убрать детерминированный planner, дать LLM самому решать что спрашивать.

**Мотивация:** 
- Заметили 2 отличных ответа в нестандартных ситуациях (Ольга, "не актуально")
- GPT умнее жёсткого сценария в нетипичных случаях

**Архитектура:**
```
Сообщение → Extractor → State Manager → [LLM видит State + RAG] → Generator
```

**В промпте:**
- Чеклист что нужно узнать (goal, budget, location, payment, lpr)
- State Manager показывает что уже известно
- Инструкция: после базовой квалификации → предложи созвон
- RAG для примеров вопросов и ответов

**Риски:**
- Может забыть спросить важное → чеклист в промпте
- Зацикливание → State показывает что известно
- Не предложит созвон → правило в промпте
- Сложнее отлаживать → логировать reasoning
