## 🔮 Исследование: Голосовая Эва (PersonaPlex)

### Цель
Научить Эву звонить клиентам и разговаривать голосом.

### Технология
**PersonaPlex от NVIDIA** — модель для голосовых разговоров в реальном времени:
- Full-duplex (слушает и говорит одновременно)
- Speech-to-Speech (голос → голос)
- Низкая задержка
- Управление персоной через промпт
- GitHub: https://github.com/NVIDIA/personaplex
- Модель: nvidia/personaplex-7b-v1 (HuggingFace)

### Архитектура (гибрид)
```
Клиент говорит по телефону
         ↓
    PersonaPlex (распознаёт речь)
         ↓
    Эва (Аналитик + RAG + Генератор) — думает, формирует ответ
         ↓
    PersonaPlex (озвучивает голосом Софии)
         ↓
    Клиент слышит ответ
```

## 🐛 Баги для исправления

### BUG-001: dialog_finished не ставится при мягком отказе
**Проблема:** Клиент говорит "сейчас неудобно", "позже свяжусь", "перезвоню" — Эва продолжает квалификацию вместо завершения.
**Ожидание:** "Хорошо, напишите когда будет удобно) [END]"
**Решение:** Добавить в промпт особый случай + научить Аналитик распознавать.

### BUG-002: Нет объединения быстрых сообщений (debounce)
**Проблема:** Клиент пишет два сообщения подряд быстро — Эва отвечает на каждое отдельно (два ответа).
**Пример:**
```
Клиент: Здравствуйте
Клиент: Какая недвижимость?
София: Здравствуйте) Подскажите...
София: Здравствуйте) Курортная недвижимость...  ← ДВА ОТВЕТА!
```
**Решение:** Добавить debounce 3-5 сек — ждать и объединять сообщения перед обработкой.
