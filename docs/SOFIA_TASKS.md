## 🔮 Исследование: Голосовая Эва (PersonaPlex)

### Цель
Научить Эву звонить клиентам и разговаривать голосом.

### Технология
**PersonaPlex от NVIDIA** — модель для голосовых разговоров в реальном времени:
- Full-duplex (слушает и говорит одновременно)
- Speech-to-Speech (голос → голос)
- Низкая задержка
- Управление персоной через промпт
- GitHub: https://github.com/NVIDIA/personaplex
- Модель: nvidia/personaplex-7b-v1 (HuggingFace)

### Архитектура (гибрид)
```
Клиент говорит по телефону
         ↓
    PersonaPlex (распознаёт речь)
         ↓
    Эва (Аналитик + RAG + Генератор) — думает, формирует ответ
         ↓
    PersonaPlex (озвучивает голосом Софии)
         ↓
    Клиент слышит ответ
```
