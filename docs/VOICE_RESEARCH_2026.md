## 1. STT — распознавание речи

### Yandex SpeechKit STT — TOP PICK для России

- **Что это:** Облачный STT от Яндекса, нативно оптимизированный под русский язык
- **Русский язык:** ЛУЧШИЙ — 95-97% accuracy, WER ~3-5% на чистой речи. Обрабатывает акценты, диалекты, разговорную речь
- **Латенси:** ~200-400ms первый partial result через gRPC streaming
- **Стриминг:** Да, gRPC с промежуточными результатами пока пользователь говорит
- **VAD:** Да, встроенный, определение границ фраз
- **Стоимость:** ~0.12-0.15 ₽ за 15-секундный сегмент ≈ $0.006-0.01/мин
- **Серверы в России:** ДА (Москва, Владимир) — минимальная сетевая задержка
- **Self-hosted:** Нет, только Yandex Cloud
- **Плюсы:** Лучшее качество русского. Серверы в РФ = ~5ms сетевой задержки. gRPC streaming. Дёшево
- **Минусы:** Зависимость от Yandex Cloud. Ограниченная поддержка языков кроме русского
- **Вердикт: ОСНОВНОЙ ВЫБОР для русскоязычного агента**

### Deepgram Nova-3 — TOP PICK для облака

- **Что это:** Облачный STT, Nova-3 — флагманская модель, заточена под real-time voice agents
- **Русский язык:** Хороший, официально поддержан. Заявлено 54.3% снижение WER vs конкуренты
- **Латенси:** <300ms time-to-first-token в стриминге. Лучший в индустрии для облака
- **Стриминг:** Да, WebSocket. Partial + final transcripts. Рекомендуемые чанки 20ms
- **VAD:** Да, встроенный. `speech_final` флаг, `SpeechStarted` event. Идеально для voice agents
- **Стоимость:** $0.0059-0.0077/мин (streaming)
- **Серверы в России:** Нет. US/EU
- **Self-hosted:** Нет
- **Плюсы:** Лучший латенси в облаке. Отличный VAD/endpointing. Русский поддержан. Хорошая цена
- **Минусы:** Нет серверов в РФ (+50-150ms из Москвы). Нет публичного WER для русского
- **Вердикт: ОТЛИЧНЫЙ ВЫБОР, особенно если сервер в EU/US**

### Soniox — стоит протестировать

- **Что это:** Облачный STT, заявляет лучший WER по 60+ языкам
- **Русский язык:** Заявлено 6.2% WER (vs 10.1% OpenAI, 16.7% Google на YouTube-аудио)
- **Латенси:** <200ms real-time streaming
- **Стоимость:** ~$0.002/мин — самый дешёвый
- **Вердикт: НАДО ТЕСТИТЬ — если 6.2% WER подтвердится, это сильнейший контендер**

### Sber SaluteSpeech STT

- **Что это:** STT от Сбера, нативный русский, Tacotron 2 + BERT
- **Русский язык:** Отличный, конкурирует с Яндексом
- **Латенси:** gRPC streaming, серверы в РФ
- **Стоимость:** ~$0.012/мин. Бесплатно 100 мин/мес
- **Серверы в России:** ДА + есть on-premise вариант
- **Self-hosted:** Частично (on-premise для enterprise)
- **Вердикт: ХОРОШАЯ АЛЬТЕРНАТИВА Яндексу. On-premise — уникальное преимущество**

### Faster-Whisper (self-hosted)

- **Что это:** Open-source ускоренный Whisper на CTranslate2. До 8x быстрее оригинала
- **Русский язык:** ~6.4% WER (fine-tuned large-v3). Хороший
- **Латенси:** GPU (V100): ~4x real-time. Но НЕТ нативного стриминга — только pseudo-streaming через чанки
- **Стоимость:** Бесплатно (GPU cost only)
- **Self-hosted:** ДА, BSD лицензия. Можно развернуть в РФ
- **Вердикт: ЗАПАСНОЙ ВАРИАНТ — нет настоящего стриминга, нужна инженерная работа**

## 2. TTS — синтез речи

### Yandex SpeechKit TTS — TOP PICK для русского

- **Что это:** TTS от Яндекса, нативно обучен на русской речи. Premium голоса с нейросетевой просодией
- **Русский язык:** ЛУЧШИЙ — нативные интонации, правильные ударения, естественные паузы. Premium голоса анализируют полный контекст текста
- **Латенси:** ~100ms TTFB через gRPC из Москвы. API v3 лимит: 250 символов / 24 сек на запрос
- **Стриминг:** Да, gRPC streaming (API v3) и REST (API v1)
- **Стоимость:** ~$2.40/1M символов (standard), ~$4.80/1M символов (premium). САМЫЙ ДЕШЁВЫЙ
- **Клонирование голоса:** Brand Voice Premium (enterprise, по заявке)
- **Серверы в России:** ДА
- **Self-hosted:** Нет
- **Плюсы:** Лучшее качество русского. Самый дешёвый. Серверы в РФ. SSML. gRPC
- **Минусы:** Лимит 250 символов на запрос (нужен chunking). Меньше эмоций чем ElevenLabs
- **Вердикт: ОСНОВНОЙ ВЫБОР**

### Cartesia Sonic 3 — НАДО ТЕСТИТЬ (скорость)

- **Что это:** Ultra-low latency TTS, 42 языка. Заточен на минимальный TTFB
- **Русский язык:** Поддержан, но не оптимизирован специально. Качество надо проверить
- **Латенси:** 40ms TTFB (Sonic Turbo), 90ms (Sonic 3) — ЛУЧШИЙ В ИНДУСТРИИ
- **Стриминг:** Да, нативный
- **Стоимость:** ~$47/1M символов
- **Клонирование голоса:** Да, 3 секунды аудио
- **Серверы в России:** Нет (US)
- **Плюсы:** 40ms TTFB — game-changer для voice agents. Клонирование. SSML с эмоциями
- **Минусы:** Русский не проверен для sales-диалогов. Нет серверов в РФ (+100-200ms)
- **Вердикт: ВЫСОКИЙ ПРИОРИТЕТ ДЛЯ ТЕСТИРОВАНИЯ — если качество русского ОК, это лучший вариант по скорости**

- **Русский язык:** Отличный — сложно отличить от человека. BERT анализирует контекст
- **Латенси:** Не опубликован, но серверы в РФ = низкий
- **Стоимость:** ~$10/1M символов. Бесплатно 200K символов/мес

- **Вердикт: ХОРОШАЯ АЛЬТЕРНАТИВА Яндексу. Чуть дороже, но отличное качество**

- **Что это:** Лидер TTS по эмоциональности и клонированию голоса. Flash v2.5 — быстрая модель
- **Русский язык:** Поддержан, но не приоритетный. Хорошо, но ниже Яндекса для русского
- **Латенси:** Flash v2.5: ~75ms TTFB (инференс). Multilingual v2: ~300-500ms
- **Стоимость:** ~$180/1M символов — САМЫЙ ДОРОГОЙ
- **Клонирование голоса:** Лучшее в индустрии. Instant (секунды) и Professional (30+ мин)

- **Плюсы:** Лучшие эмоции. Лучшее клонирование. Отличный стриминг
- **Минусы:** Очень дорого. Русский — не приоритет. Нет серверов в РФ

## 3. LLM — модели для голосового канала

### Текущая ситуация

Полный пайплайн (gpt-5.2 с reasoning):
- Extractor: ~2-3с (reasoning overhead)
- Analyzer: ~2-3с (reasoning=medium)
- RAG: ~50ms
- Generator: ~3-5с (reasoning=high)
- **Итого: ~7-11с последовательно**

В voice_mode отключены Extractor и Analyzer → ~3-5с, но София "тупее".

### gpt-4.1-mini — TOP PICK для голоса

- **TTFT:** 0.73с (OpenAI direct)
- **Скорость:** 73 tok/s
- **Русский:** Хороший (тот же токенизатор что GPT-4.1)
- **Стоимость:** $0.40/1M input, $1.60/1M output — в 15x дешевле gpt-5.2
- **Reasoning:** НЕТ — нет скрытого CoT delay. Предсказуемый TTFT
- **Вердикт: ОСНОВНОЙ ВЫБОР для голосового Generator. Без reasoning = стабильные 0.7с TTFT**

### Groq + Qwen3-32B — TOP PICK для Extractor/Analyzer

- **TTFT:** ~0.1-0.3с
- **Скорость:** 400-1000+ tok/s (5-10x быстрее OpenAI)
- **Русский:** Хороший (Qwen3 обучен на 201 языке, русский включён)
- **Стоимость:** ~$0.05-0.50/1M
- **Вердикт: ЛУЧШИЙ для латенси-критичных компонентов. Extractor (JSON extraction) за 0.3с**

### Claude Haiku 4.5

- **TTFT:** 0.55-0.66с
- **Скорость:** 94 tok/s
- **Русский:** Хороший
- **Стоимость:** $0.80/1M input, $4.00/1M output
- **Вердикт: АЛЬТЕРНАТИВА gpt-4.1-mini для Generator. Чуть быстрее TTFT, но дороже**

### Cerebras + Qwen3-235B

- **Скорость:** 2000-3000 tok/s — САМЫЙ БЫСТРЫЙ В МИРЕ
- **TTFT:** ~0.1-0.2с
- **Русский:** Хороший (Qwen3-235B)
- **Вердикт: АЛЬТЕРНАТИВА Groq. Ещё быстрее, но менее проверен в продакшене**

## 4. Архитектура голосового пайплайна

### Паттерн 1: Параллельный запуск

```
Транскрипция готова
    ├─ Extractor (Groq)     [параллельно]
    ├─ RAG поиск (ChromaDB)  [параллельно]
    └─ Загрузка state из БД  [параллельно]
         └─ Всё готово → Generator (streaming)
```
**Эффект:** -200-400ms. Используют ВСЕ продакшн voice agents (Bland, PolyAI, Sierra).

### Паттерн 2: Асинхронное обновление state

```
Транскрипция → Generator генерирует ответ → стрим в TTS
                 ПАРАЛЛЕЛЬНО: обновить client_state, Bitrix, логи
```
**Эффект:** -50-150ms. Не ждём записи в БД перед ответом. Универсальный паттерн.

### Паттерн 3: Каскадная генерация (два модели)

```
Клиент: "Сколько стоит двушка в Дубай Марина?"

Быстрая модель (50ms): "О, Дубай Марина — отличный выбор!"     ← начинает TTS сразу
Полная модель (800ms):  "Двушки там сейчас от $350K до $550K..."  ← подключается позже
```
**Эффект:** Perceived latency ~200ms. Используют Bland.ai ("turbo mode"), PolyAI.
**Важно:** Филлер должен быть контекстным, не generic.

### Паттерн 4: Предиктивный контекст (pre-fetching)

```
Клиент говорит: "Меня интересует..."
    → Partial transcript → pre-load история клиента
Клиент говорит: "...квартиры в Business Bay..."
    → Partial transcript → RAG поиск "Business Bay"
Клиент замолчал:
    → Полная транскрипция, но RAG результаты УЖЕ готовы
```
**Эффект:** -200-500ms RAG lookup. "Секретное оружие" Sierra и Parloa.
**Требует:** Streaming STT с partial results (Deepgram, Yandex SpeechKit — оба поддерживают).

### Паттерн 5: Спекулятивное выполнение

```
София: "Хотите записаться на просмотр?"
    → Пока ждём ответа, pre-generate:
       - "Да" → готов flow бронирования
       - "Нет"/возражение → готова обработка возражений
       - "Когда?" → готово предложение времени
Клиент: "А когда можно?"
    → Ответ уже готов, мгновенно
```
**Эффект:** Near-zero latency для предсказуемых веток. Работает для sales-диалогов!
**Используют:** Parloa (enterprise), Sierra (retail).

### Паттерн 6: Voice-specific промпт

Голосовые ответы должны быть принципиально другими:
- **Длина:** 1-3 предложения максимум (не 5-8 как в тексте)
- **Структура:** Никаких списков, только разговорный поток
- **Подтверждения:** Чаще переспрашивать ("Правильно понимаю, вас интересует двушка?")
- **Окончание:** Всегда вопросом (стимулирует ответ, предотвращает неловкие паузы)

```python
# Добавка к voice prompt:
"Отвечай 1-2 предложениями. Всегда заканчивай вопросом.
Никогда не перечисляй больше 2 вариантов за раз.
Используй разговорный русский, избегай сложных конструкций."
```

### Оптимальный стриминг в TTS

- Слишком мелкие чанки (пословно) → TTS не может создать нормальную просодию, рвано
- Слишком крупные (целые предложения) → задержка пока предложение сгенерируется
- **Оптимум: уровень клаузы** — 15-40 символов, разбивка на `.`, `,`, `—`, `;`, `!`, `?`

## 5. Оркестрация — замена Retell

### Pipecat (Daily.co) — TOP PICK open-source

- **Что это:** Open-source Python фреймворк для голосовых агентов. Frame-based pipeline
- **GitHub:** 10.1k stars, очень активный (обновления март 2026)
- **Архитектура:** Транспорт → VAD → STT → LLM → TTS → Аудио. Каждый компонент — "процессор"
- **Интеграции:** 40+. Deepgram/Whisper STT, ElevenLabs/Cartesia/Yandex TTS, OpenAI/Anthropic/Groq LLM
- **Транспорт:** Daily WebRTC, Twilio/Telnyx WebSocket, raw WebSocket
- **Телефония:** SIP через Twilio/Telnyx media streams → Pipecat WebSocket
- **Латенси:** 500-800ms voice-to-voice типично. 1с с open models
- **VAD:** Silero VAD встроен. Прерывания настраиваются
- **Сложность:** Средняя. ~100 строк для базового бота. +50 строк для телефонии
- **Стоимость:** Фреймворк бесплатный. Daily transport $0.004/мин
- **Плюсы:** Самый зрелый OSS. Vendor-neutral. Отличная документация. Активное сообщество
- **Минусы:** Daily — US/EU (нет РФ endpoint). Нужен свой SIP провайдер
- **Вердикт: ЛУЧШИЙ ВЫБОР для self-hosted решения**

### LiveKit Agents — сильный #2

- **Что это:** Open-source, WebRTC-based. Нативный SIP bridge
- **Архитектура:** SIP/WebRTC → LiveKit Room → Agent (STT→LLM→TTS) → Аудио
- **Ключевое:** Нативный SIP bridge + transformer-based turn detection (лучше простого VAD)
- **Телефония:** First-class SIP, любой SIP trunk (включая Задарма)
- **Сложность:** Средняя-Высокая. LiveKit сервер тяжелее Pipecat
- **Плюсы:** Лучшая SIP интеграция. Scalable WebRTC. Можно video agents. Self-hostable
- **Минусы:** Тяжелее инфраструктура. Более opinionated (всё через "rooms")
- **Вердикт: ОТЛИЧНЫЙ ВЫБОР если нужна интегрированная SIP телефония**

### Vapi — самая простая миграция

- **Что это:** Managed платформа, аналог Retell. Custom LLM через webhook/WebSocket
- **Архитектура:** Как Retell — платформа управляет STT/TTS/VAD, вы отвечаете текстом
- **Русский:** Заявлен (100+ языков), через Deepgram/ElevenLabs
- **Телефония:** Встроенная + ЗАДАРМА SIP интеграция задокументирована!
- **Стоимость:** $0.05/мин base + провайдеры = $0.07-0.25/мин
- **Сложность:** НИЗКАЯ — минимальные изменения в voice_api.py
- **Плюсы:** Drop-in замена Retell. Задарма интеграция. Нет инфраструктуры
- **Минусы:** Та же зависимость от managed платформы. $0.05/мин base. Меньше контроля
- **Вердикт: САМЫЙ БЫСТРЫЙ ПУТЬ миграции с Retell**

### Не подошли

| Решение | Причина |
|---------|---------|
| Vocode | Полу-заброшен, ищут maintainers. Риск |
| Bland.ai | Русский не проверен, дороже, менее гибкий |
| Bolna | Менее зрелый чем Pipecat, меньше интеграций |
| Custom WebSocket | 2-4 недели работы на то, что Pipecat даёт бесплатно |

### Сводная таблица оркестрации

| Решение | Тип | Латенси | Сложность | Телефония | Стоимость фреймворка | Вердикт |
|---------|-----|---------|-----------|-----------|---------------------|---------|
| **Pipecat** | OSS | 500-800ms | Средняя | SIP через Twilio/Telnyx | Free | **TOP PICK** |

### ФЗ-152 (персональные данные)

- Персональные данные граждан РФ должны храниться на серверах в РФ
- Трансграничная передача разрешена в страны с адекватной защитой (ЕС, США с условиями)
- Голосовые записи с ПД (имя, телефон, адрес) подпадают под ФЗ-152
- **Безопасный подход:** Голос обрабатывать в РФ (Yandex STT/TTS), за рубеж отправлять только анонимизированный текст
- **Практический подход:** Большинство компаний включают это в Privacy Policy и получают согласие. Enforcement фокусируется на крупных нарушениях
- **Контекст Софии:** Основная аудитория — инвесторы в зарубежную недвижимость, многие не граждане РФ или взаимодействуют из-за рубежа

## 9. Три рекомендованные архитектуры

### Вариант 1: БЫСТРЫЙ — минимальные изменения, максимальный эффект

**Суть:** Оставить Retell (или мигрировать на Vapi), но поменять LLM и добавить post-processing.

```
Клиент → Retell/Vapi (STT + VAD + TTS)
    → WebSocket → voice_api.py
    → gpt-4.1-mini Generator (вместо gpt-5.2)
    → текст ответа → Retell/Vapi → клиент

ASYNC после ответа:
    → gpt-5.2 Extractor (обновление state)
    → Bitrix CRM update
```

**Что меняем:**
1. В `core/pipeline.py` → `stream_voice_response()`: заменить gpt-5.2 на gpt-4.1-mini
2. Добавить voice-specific prompt ("1-2 предложения, заканчивай вопросом")
3. После генерации ответа → async запуск Extractor (gpt-5.2) для обновления state
4. Опционально: мигрировать с Retell на Vapi + Задарма SIP

**Ожидаемый латенси:** ~1.5-2с (voice-to-voice)
- STT (Retell/Deepgram): ~300ms
- LLM (gpt-4.1-mini): ~700ms TTFT + streaming
- TTS (Retell/ElevenLabs): ~200ms
- Сеть: ~300ms

**Стоимость/мин:**
- Retell: $0.07-0.14 (или Vapi: $0.05 base + провайдеры ≈ $0.10)
- gpt-4.1-mini: ~$0.01
- **Итого: ~$0.08-0.15/мин**

**Сроки:** 1-2 дня

**Риски:** Минимальные. Retell/Vapi всё ещё контролирует STT/TTS/VAD

**Что даёт:**
- Скорость: ~2с вместо ~5с
- Качество: async Extractor возвращает умный state tracking
- Стоимость LLM: в 15x дешевле

- Сложность: много движущихся частей
- Каскадная генерация может давать неестественные переходы
- Спекулятивное выполнение — доп. расход на неиспользованные ответы
- Fish Audio/Cartesia русское качество нужно верифицировать

**Что даёт:**
- Латенси ~0.5с — быстрее человека-оператора
- Полный pipeline без деградации — голосовая София = текстовая София по качеству
- Кастомный голос "Софии"
- Полный контроль, никакой зависимости от managed платформ
- Масштабируется дёшево
