# 🐛 Баги Sofia-GPT

## ✅ ИСПРАВЛЕНО

### BUG-001: dialog_finished не ставится при мягком отказе
**Дата:** 2026-02-02
**Коммит:** e74edc6b

**Проблема:** Клиент говорит "сейчас неудобно", "позже свяжусь", "перезвоню" — Эва продолжает квалификацию вместо завершения.

**Решение:** Добавлен блок в `sofia_prompt_v2.py`:
- Распознаёт фразы "сейчас неудобно", "я сам напишу", "позже свяжусь"
- София уважает когда клиент берёт контроль
- Отвечает "Хорошо, напишите когда будет удобно) [END]"

---

### BUG-002: Дубли сообщений (race condition)
**Дата:** 2026-02-02
**Коммит:** e74edc6b

**Проблема:** Клиент пишет два сообщения подряд — Эва отвечает на каждое отдельно (два ответа).

**Причина:** `asyncio.create_task()` запускал параллельную обработку каждого сообщения.

**Решение:** Создан модуль `message_queue.py`:
- Lock на user_id — одновременно обрабатывается только одно сообщение
- Очередь — новые сообщения копятся пока идёт обработка
- Перед отправкой проверяется очередь — если есть новые, объединяются и перегенерируется ответ

**Откат:** `/opt/sofia-gpt/backup_20260202_132448_pre_queue/ROLLBACK.sh`
